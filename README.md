# Kika

**TWENTY YEARS, 35 COUNTRIES, 1000+ SHOWS. THEN I STARTED BUILDING SYSTEMS.**

Not a developer in the traditional way. Not a DJ anymore.

I build things. I care about the details. Most tools start because my own workflow broke and I wanted a better ritual.

**AGENT-FIRST INFRA, TOOLS, AND MANY RANDOM NIGHT BUILDS. DESIGNED BY SOMEONE WHO ACTUALLY USES IT.**

### Infra for agents

- **[the-librarian](https://github.com/aka-kika/the-librarian)**: a skill librarian for coding agents. The whole collection stays out of their context; they ask and get the few right skills.
- **[hig-mcp](https://github.com/aka-kika/hig-mcp)**: Apple's design guidelines as structured tokens, Liquid Glass included.
- **[kika-obsidian-mcp](https://github.com/aka-kika/kika-obsidian-mcp)**: an Obsidian vault for agents. No plugins, no API keys.
- **[launchd-audit](https://github.com/aka-kika/launchd-audit)**: every background job on a Mac, in plain words.
- **[akakika-skills](https://akakika-skills.vercel.app)**: 40 plain skills for building calm, native software with agents.

### Tools I use every day

- **[mcpock](https://mcpock.com)**: a menu bar app that checks every MCP server your agents use.
- **[Personal Ops Manual](https://ops-manual.akakika.com)**: one page per machine, service and agent. Agents read it, one operator writes it.
- **[Pallet](https://akakika.com/pallet)**: color palettes from images and the screen, on this device.
- **[reshelf](https://aka-kika.github.io/reshelf/)**: the open-source repos I actually use, sorted and cloned.
- **[Sift](https://sift.akakika.com)**: explains, scores and tracks every app on a Mac.
